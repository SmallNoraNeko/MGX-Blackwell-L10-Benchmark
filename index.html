Containerized Execution

Docker

Base image: NVIDIA CUDA 12.8 + Ubuntu 24.04. Proprietary binary tools are not included — mount tools/ as a volume at runtime.

Build
$ docker build \
    -t night-kuronos/mgx-blackwell-l10-benchmark:1.0.1 \
    .
Run
$ docker compose run benchmark

# or manually:
$ docker run --rm -it \
    --runtime=nvidia --gpus all \
    --network host --privileged \
    -v ./tools:/workspace/tools:ro \
    -v ./report:/workspace/report:rw \
    night-kuronos/mgx-blackwell-l10-benchmark:1.0.1

Personal Portfolio Project. This benchmark suite was engineered for a single, specific MGX Architecture Blackwell L10 Standalone deployment and is published here as a personal technical portfolio piece.

Reproduction requires: identical MGX hardware topology, proprietary binary tools (not distributed in this repository), and site-specific RDMA and PCIe configurations. Not maintained as an open-source project.
